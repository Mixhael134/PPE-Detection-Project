# Dataset Documentation

## Dataset Name

SH17 Dataset for PPE Detection

## Source

Kaggle

## Description

This dataset contains images of workers wearing personal protective equipment (PPE) such as helmets and safety vests.

The dataset was used to train a YOLOv8 object detection model for PPE detection.

## Classes

* person
* helmet
* vest

## Folder Structure

### raw/

Contains original dataset images before preprocessing.

### preprocessed/

Contains reorganized or processed images prepared for YOLOv8 training.

### sample/

Contains sample images used for demonstrations and quick testing.

## Notes

The full dataset was not uploaded to GitHub due to file size limitations.
