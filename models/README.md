# Model Documentation

## Pretrained Model

The project used the YOLOv8n pretrained model from Ultralytics as the base model for transfer learning.

## Trained Model

The trained model weights are stored in the `trained/` folder.

Model:

* YOLOv8n
* Trained on the SH17 PPE Detection Dataset

## Purpose

The trained model performs object detection for:

* person
* helmet
* vest

The model generates bounding boxes and confidence scores for PPE detection in workplace environments.
